## 1. 发现项目根目录

按以下顺序定位：

1. 查找 `project.config.json`、`project.private.config.json`。
2. 读取 `miniprogramRoot`；为空时项目目录通常即小程序根。
3. 在根目录确认 `app.json`、`app.js|ts`、`app.wxss`、`pages`。
4. 查找 `package.json`、`pnpm-workspace.yaml`、框架配置和构建产物。
5. 区分源码目录与开发者工具实际打开的产物目录。

不要把 `dist`、`.git`、`node_modules`、代码上传私钥、支付证书和本地私有配置打入代码包。

## 2. 配置与目录

### `app.json`

检查：

- `pages` 和 `subPackages|subpackages` 路由真实存在；
- `tabBar` 页面必须在注册路由中；
- `usingComponents` 只做真正全局使用的组件；
- `preloadRule`、`lazyCodeLoading` 与分包策略一致；
- `networkTimeout` 有业务依据；
- `permission`、`requiredPrivateInfos` 和后台隐私声明一致；
- 不把 `sitemap.json` 或 `sitemapLocation` 当作现行发布必需项；官方旧 Sitemap 页面已失效。遗留项目若仍保留该配置，只校验引用文件与现有后台策略，不为“过审”机械补文件；
- DarkMode、主题、Skyline 等可选能力有目标基础库和回退方案。

### 页面与组件

保持页面四件套或 TypeScript 对应文件清晰：

```text
pages/example/
  index.ts
  index.json
  index.wxml
  index.wxss
```

把低频业务放入分包；把高频更新区域封装为小组件；避免全局注册大量只在单页使用的组件和插件。

### 私有配置

`project.private.config.json` 只保存本地开发偏好，不依赖其承载生产必需配置。用环境变量、CI 密钥库或云密钥管理保存代码上传私钥和后端密钥。

## 3. 生命周期与更新

区分：

- App：`onLaunch`、`onShow`、`onHide`、错误与未处理 Promise；
- Page：加载、显示、就绪、隐藏、卸载；
- Component：created/attached/ready/moved/detached 和 pageLifetimes；
- 冷启动、热启动、后台恢复和版本更新。

不要在 `onLaunch` 立即请求与首屏无关的数据、申请隐私权限或加载全部低频模块。

实现 UpdateManager：

```js
const manager = wx.getUpdateManager()

manager.onUpdateReady(() => {
  wx.showModal({
    title: '更新提示',
    content: '新版本已准备好，是否立即重启？',
    success: ({ confirm }) => confirm && manager.applyUpdate(),
  })
})

manager.onUpdateFailed(() => {
  // 记录失败；向用户提供稍后重试，而非死循环重启
})
```

发布新版本后仍需让服务端兼容旧客户端。官方说明全量发布后通常仍需时间覆盖，不得把前端更新当数据库迁移的原子开关。

## 4. 页面、组件和状态

### 数据原则

- `data` 只放渲染相关字段。
- 非渲染状态放实例字段或领域服务。
- 对数组/对象使用路径级 `setData`，不调用 `this.setData(this.data)`。
- 合并连续更新，避免毫秒级 setData 和 `onPageScroll` 每帧更新。
- 对后台页面停止无价值的计时器、轮询和渲染。

### 组件原则

- 组件对外用 properties、events、slots 和清晰方法契约。
- 避免父页面跨层直接修改子组件内部状态。
- 给 `wx:for` 提供稳定 `wx:key`，不要使用会变化的数组下标作为业务身份。
- 处理组件卸载后的异步回调，避免 setData 到已销毁实例。

### 路由与导航

- 确认 tabBar 使用 `switchTab`，普通页使用正确的 navigate/redirect/reLaunch。
- 保持返回、左滑和系统返回行为符合用户预期。
- 控制页面栈深度，长流程保存必要状态并提供中断恢复。
- 分享链接、二维码、Scheme、URL Link 的入口参数都做白名单解析和权限校验。

## 5. 网络与服务端

官方网络约束：

- `wx.request`、上传、下载使用 HTTPS；WebSocket 使用 WSS。
- 域名必须预先配置，不能使用公网 IP 或 localhost，且通常需 ICP 备案。
- `api.weixin.qq.com` 不得配置为小程序请求域名；AppSecret 和 access_token 调用放后端。
- TLS、证书域名、有效期和完整信任链必须正确；关闭工具的“跳过域名/TLS/证书校验”后真机测试。
- 请求默认超时可由全局或单请求配置；根据业务设置更短的可恢复超时。

封装请求层：

- 基础 URL 和环境隔离；
- 会话注入和过期刷新；
- 超时、取消、统一错误映射；
- 幂等键和重复点击保护；
- 可重试只用于幂等请求，指数退避并设上限；
- 记录 request ID，不记录 token、手机号、证件、完整响应体等敏感数据。

后端对每个敏感接口执行：

1. 认证调用者。
2. 校验角色与资源归属，防平行/垂直越权。
3. 校验类型、范围、长度、枚举和状态机。
4. 不信任前端价格、折扣、库存、权限和订单结果。
5. 使用参数化查询；限制上传类型、大小、存储路径和下载范围。
6. 对奖励、库存、优惠、支付回调和重复提交做事务/锁/幂等。
7. 记录可追溯审计日志。

## 6. 登录与身份

标准流程：

```text
小程序 wx.login()
  -> 一次性 code 发送到开发者后端
  -> 后端调用 auth.code2Session
  -> 获得 OpenID / UnionID（满足条件时）/ session_key
  -> 后端生成自身会话
  -> 小程序只持有开发者会话，不持有 session_key
```

规则：

- code 只能使用一次，避免并发重复消费。
- 不把 openid 当秘密，但不能相信前端自报的 openid。
- 不把 session_key 下发、写日志或长期持久化。
- UnionID 依赖开放平台绑定条件，不能假设必有。
- 登录不等于取得头像、昵称、手机号或隐私同意。
- 普通个人主体不能使用手机号快速验证组件；设计非强制手机号的账号/联系流程。
- 当前头像昵称完善优先使用 `button open-type="chooseAvatar"` 与 `input type="nickname"`。

提供退出登录、会话撤销、账号注销和数据删除。用户拒绝某个非核心权限时，不中止无关功能。

## 7. 兼容与终端

### 基础库

- 从对应组件/API 文档读取最低基础库。
- 使用 `wx.getAppBaseInfo().SDKVersion` 读取版本；旧基础库按官方兼容说明降级。
- 不直接按字符串比较版本号。
- 对新增 API 做存在判断或 `wx.canIUse`，并提供可理解的降级。
- 设置最低基础库前查看近 30 天用户分布，评估被阻断用户比例。

### 终端矩阵

至少考虑 iOS、Android；按业务覆盖 HarmonyOS、Windows、macOS、大屏、深色模式、字号放大和无障碍。

不要仅在开发者工具判断：

- 授权弹窗、支付、位置、蓝牙、相册、相机；
- 键盘顶起、安全区域、状态栏和胶囊按钮；
- 网络证书、域名、缓存、更新和性能；
- Skyline/WebView 等渲染差异。

## 8. npm、工具和 CI

### npm

- 固定依赖版本与锁文件。
- 构建 `miniprogram_npm` 后检查实际打包文件。
- 清除未使用依赖、demo、map、测试数据和大资源。
- 审计开源许可证和第三方 SDK 数据行为。

### 开发者工具 CLI / 自动化

- 使用开发者工具真机预览和质量面板。
- 使用 `miniprogram-automator` 做关键 UI 流程自动化。
- 自动化不能完全代替真实微信账号、权限、支付和弱网测试。

### `miniprogram-ci`

可用于预览、上传和构建 npm。安全要求：

- 从 MP 后台生成代码上传密钥；默认开启 IP 白名单。
- 私钥只放 CI 密钥库或受限文件系统，不提交仓库。
- 为不同环境/机器人记录版本、描述、commit、构建产物和操作者。
- 上传前运行测试、静态审计、包体检查、隐私清单差异和审核资料生成。
- 不让任意 PR 或不受信分支获得生产上传密钥。

## 9. 云开发

使用云函数、云数据库、云存储时：

- 为环境、集合、存储路径配置最小权限安全规则。小程序端数据库请求受安全规则限制，但云函数和控制台具有更高权限，不能据此跳过业务鉴权；
- 在云函数重新校验身份、角色、资源 owner、字段白名单和状态机，不只依赖“天然鉴权”或“已登录”；
- 不沿用默认宽松存储权限保存身份证、合同、私聊附件或未公开 UGC；私密文件使用受限规则和短期访问 URL；
- 隔离开发/测试/生产环境 ID；
- 限制上传文件和公开 URL，清理过期临时文件；
- 对数据库查询建立索引、分页和上限；
- 记录费用、配额、备份、恢复和供应商退出方案；
- 不因存在微信支付云调用就跳过主体支付门禁。

2026-07-12 计费快照仅用于预算起点：官方页面当前称新用户可体验一个基础套餐等额环境；开发阶段免费活动截至 2026-12-31，未发布时可免费，发布后环境到期时间调整为上线后第 15 天；基础套餐当前为 19.9 元/月并含 20 万次调用、2GB 容量等。所有价格、活动、配额和到期处置在立项与上线前实时读取[计费说明](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloud/billing/price.html)，不要把快照写死进报价。

把到期当作生产事故风险：配置费用告警、自动续费或人工续费负责人、数据备份和恢复演练。当前计费页说明套餐到期后存在短暂找回期，随后环境可能释放且数据不可恢复；不能让“免费环境”在正式发布后无人负责。

## 10. 日志与运维

建立：

- 客户端错误、未处理 Promise、接口错误码和版本号；
- 服务端 request ID、用户匿名标识、权限结果、状态迁移；
- 内容审核、举报、处置与申诉记录；
- 备案、类目、隐私和资质变更日历；
- 告警、值班、降级、恢复和事后复盘。

日志不得记录：AppSecret、session_key、完整 token、支付私钥、身份证、银行卡、完整手机号、原始生物信息或用户私密内容。必要字段做最小化和脱敏，并设置保留期与访问控制。
