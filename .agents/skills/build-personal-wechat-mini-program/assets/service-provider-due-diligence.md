# 个人服务商路线尽调清单

适用于服务商快速注册个人、代认证个人或个人升级版小程序。

## 官方能力

- [ ] 服务商提供微信开放平台第三方平台主体全称和官方能力页面截图。
- [ ] 已核验其具备快速注册个人、代认证或个人升级版中的具体能力。
- [ ] 个人升级版服务商考核状态和交易保证金安排符合官方要求。
- [ ] 明确当前类目、支付、退款、结算、接口和备案支持范围。

## 控制权

- [ ] AppID 主体始终为真实个人，管理员和找回方式归个人控制。
- [ ] 代码、模板、源码、域名、云环境、数据库和对象存储归属明确。
- [ ] 支付特约商户号、结算账户、发票/税务和资金冻结责任明确。
- [ ] 服务商停止服务时可导出代码、数据、订单、用户授权和审核材料。
- [ ] 不要求交出个人微信密码、身份证原件或不必要的长期权限。

## 数据与合规

- [ ] 明确个人与服务商谁是个人信息处理者/受托处理者。
- [ ] 列出服务商 SDK、服务器域名、数据字段、保留期和删除机制。
- [ ] 约定内容安全、投诉、退款、交易争议和监管协作责任。
- [ ] 禁止租借商户号、个人收款码、外部支付和审核后开关。

## 商务与退出

- [ ] 费用、抽成、保证金、退款损失、广告分成和涨价规则透明。
- [ ] SLA、故障、数据丢失、审核失败和违规处罚责任明确。
- [ ] 合同终止、主体迁移、服务商失去能力、商户号关闭的方案明确。
- [ ] 争议管辖、知识产权、开源许可证和保密条款明确。

结论：可接受 / 有条件接受 / 不接受
