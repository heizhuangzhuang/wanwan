# 小程序主体/新 AppID 迁移清单

## 路线

- [ ] 新建组织主体 AppID / 原 AppID 主体变更（后台证据：）
- [ ] 目标主体、管理员、认证、备案、类目、资质均已确认。
- [ ] 已核验商户号、支付/广告服务商、广告余额、插件和公众号关联阻塞。
- [ ] 费用、公证、审核时限和失败退款规则以操作当天页面为准。

## 身份与数据

- [ ] 已记录旧/新 AppID、开放平台绑定和 OpenID/UnionID 行为。
- [ ] 不用姓名、手机号等弱证据静默合并账号。
- [ ] 设计重新登录、账号证明、用户确认、冲突处理和申诉。
- [ ] 历史订单、会员/权益、余额、优惠、内容、收藏和售后映射可追溯。
- [ ] 迁移具有合法依据，已更新隐私告知、接收主体、目的和删除方式。
- [ ] 数据导出、校验和导入使用加密传输、最小权限和审计日志。

## 产品与能力

- [ ] 目标主体重新申请全部真实服务类目与资质。
- [ ] 名称、简介、Logo、备案服务内容、隐私指引和页面同步更新。
- [ ] 登录、订阅、客服、URL Link/Scheme、二维码、插件、云环境和域名重配。
- [ ] 支付下单、回调、退款、对账、投诉和历史订单查询完成迁移。
- [ ] 旧版客户端与新后端有兼容窗口，不一次性删除旧字段/接口。

## 用户沟通与验证

- [ ] 提前告知迁移主体、时间、影响、权益、隐私变化和联系渠道。
- [ ] 提供不同意迁移时的导出、退款、注销或删除路径（按适用规则）。
- [ ] 使用脱敏副本演练迁移并核对数量、金额、权益和抽样记录。
- [ ] iOS/Android 体验版覆盖新老用户、未迁移、冲突账号和失败重试。
- [ ] 准备只读/双写/回滚方案、冻结窗口、负责人和事件预案。
- [ ] 正式迁移后验证登录、类目、备案、支付、隐私、订单、客服和监控。
