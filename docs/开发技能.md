# 开发技能

克隆仓库或拉取 `main` 后，在项目目录打开 Codex。Codex 会从 [`.agents/skills/`](../.agents/skills/) 发现这 30 项项目技能。可以直接在对话中输入 `$技能名`，例如 `$ui-ux-pro-max 改进小程序的穿戴记录页`。已全局安装同名技能时，选项目目录里的版本。技能的发现规则见 [Codex 官方文档](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)。

| 开发任务 | 可用技能 |
| --- | --- |
| 微信小程序开发、组件与上架 | `miniprogram-development`、`wechat-miniprogram`、`tdesign-miniprogram`、`build-personal-wechat-mini-program` |
| Web 和小程序 UI | `frontend-design`、`ui-design`、`ui-ux-pro-max`、`web-design-guidelines` |
| Web 流程测试与 GitHub Actions 排查 | `webapp-testing`、`playwright`、`gh-fix-ci` |
| 架构设计及决策记录 | `architecture-blueprint-generator`、`create-architectural-decision-record`、`cloud-design-patterns` |
| API、云托管和代码审查 | `openapi-to-application-code`、`cloudrun-development`、`multi-stage-dockerfile`、`security-review`、`sql-code-review` |
| Java 和 Spring Boot | `java-development`、`java-springboot`、`create-spring-boot-java-project`、`java-hibernate-jpa`、`spring-security`、`spring-boot-testing`、`java-junit` |
| 涉及相应技术栈时选用 | `vercel-react-best-practices`、`vercel-composition-patterns`、`postgresql-optimization`、`protobuf-grpc-api-review` |

当前系统由 Node SSR Web、Halo 业务插件（含 Vue 管理后台）、MySQL 和原生微信小程序组成。React、PostgreSQL、gRPC 与 Spring Boot 项目脚手架按具体任务使用。应用的构建、数据库和发布要求见 [技术架构与实施方案](./技术架构与实施方案.md)。

## 本机工具接入

- **UI/UX Pro Max** 随仓库提供数据和 Python 3 脚本。在仓库根目录可以运行以下命令，查询移动端穿戴记录表单的可访问性规范。

  ```bash
  python3 .agents/skills/ui-ux-pro-max/scripts/search.py \
    "form accessibility touch target focus" --domain ux -n 5
  ```

- **微信开发者工具** 的 `wechatide-skill` 和编译、调试、自动化、预览等子技能随支持该功能的开发者工具发行。各成员安装后运行 `wechatide`，按输出提示导入内置技能并用自己的微信登录。需要 MCP 时，在开发者工具的「设置 → 安全」复制本机 MCP 配置到自己的客户端，由项目管理员分配小程序开发权限。[微信开发者工具下载](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) · [CloudBase 调试接入说明](../.agents/skills/miniprogram-development/references/devtools-debug-preview.md)
- **CloudBase** 涉及云资源操作或部署时，先按官方接入说明安装完整插件，用其中的平台协议和配套技能，并接入对应环境。[CloudBase 接入文档](https://docs.cloudbase.net/skill.md)
- **浏览器测试** 使用 `playwright` 时需要 Node.js 和 npm，使用 `webapp-testing` 时需要 Python Playwright 及浏览器。进入仓库后按各技能的说明运行。[Playwright CLI](../.agents/skills/playwright/SKILL.md) · [Web 应用测试](../.agents/skills/webapp-testing/SKILL.md)
- **GitHub Actions** 用 `gh-fix-ci` 查看构建日志时需要已登录的 GitHub CLI 和仓库权限。[GitHub Actions 检查流程](../.agents/skills/gh-fix-ci/SKILL.md)
- **Figma** 按 Figma 开发者条款从官方插件或上游获取 `figma-create-design-system-rules`、`figma-generate-design`、`figma-implement-design`，在本机连接 Figma MCP。[Figma 技能下载](https://github.com/openai/skills/tree/49f948faa9258a0c61caceaf225e179651397431/skills/.curated) · [Figma 开发者条款](https://www.figma.com/legal/developer-terms/)
