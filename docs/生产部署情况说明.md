## 接手顺序

1. 在 Halo 管理后台核对「弯弯知识导航」插件 `wanwan`。按实际状态安装或启用。插件已启用时查看启动日志并核对 [匿名读取角色](../plugin-wanwan/src/main/resources/extensions/roles.yaml)。管理接口沿用 Halo 权限。
2. 从广州服务器验证匿名接口，先检查原始状态码、内容类型和 `Location`，再核验 JSON 结构。`stages` 应返回 `200` 和阶段数组，`resources`、`topics`、`posts`、`search` 应返回 `200` 和分页对象。当前跟随重定向会得到 `200 text/html` 的登录页。

   ```bash
   api='https://wanwan-332939-5-1512954837.sh.run.tcloudbase.com/apis/api.wanwan.run/v1alpha1'
   curl -sS --max-time 15 -D - -o /dev/null -H 'Accept: application/json' "$api/stages"
   curl -fsS --max-time 15 -H 'Accept: application/json' "$api/resources?page=1&size=1"
   ```

3. 匿名接口通过后，先备份 `/etc/wanwan-web.env`，再将 `BACKEND_API_BASE` 设置为已验证的 API 基地址并执行 `sudo systemctl restart wanwan-web.service`。从公网核验 `/wanwan/`、`/wanwan/stages`、`/wanwan/resources` 和带关键词的 `/wanwan/search`。如果新配置导致故障，恢复备份并重启该服务。
4. 小程序填写真实 AppID，使用 `cloudEnv=prod-d8goya17ka2d1a272`、`cloudService=wanwan`。当前仓库配置使用 `touristappid`，本地联调可走 HTTP。发布前在真实 AppID 下验证首页、资料浏览、关键词搜索和公众号落地页。
