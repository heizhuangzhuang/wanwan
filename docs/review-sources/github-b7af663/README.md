## 当前阶段

项目处于规划与需求验证阶段。用户情境为设计推演；尚未完成新增真人访谈、医生审阅、产品开发、技术小样或上线测试。医生合作、服务接口和商业模式为拟议方案，不代表已有机构签约或收入。

医学相关内容用于产品规划与就诊沟通准备，具体检查与治疗由接诊团队结合个体情况确定。本仓库只存规划资料，不存私人病历、真实账号或运行密钥。本版不含预算。
