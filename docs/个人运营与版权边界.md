# 弯弯：个人运营与知识导航版权边界

版本：5.0｜核查：2026-11-12｜当前模式：手动精选资料导航。

本文是依据公开规则形成的项目分析，没有外部律师或主管部门参与审定，不表示已完成备案、许可或渠道确认。详细历史讨论保留在[公众 RAG 综合评审](./个人运营与公众RAG可行性综合评审-v3.0.md)。

## 1. 当前采用的边界

公开原标题与必要来源信息、运营者独立撰写的简短介绍和合法原文入口。首版不自动采集全文，不复制第三方封面与图表，不提供论文全文下载，不提供公众 AI 问答。

这能够减少直接复制、采集与生成环节的风险，不能概括为已经获得著作权人授权、无论什么来源均可收录或个人医疗主题网站当然可以上线。

## 2. 对用户提供法律说明的校正

用户粘贴材料中的总体方向可作为产品建议，但以下法律结论需要限定：

- 《信息网络传播权保护条例》第二十三条有适用对象、通知处理及明知应知等条件，不能拿它作为所有人工精选导航的普遍免责承诺。人工筛选和编写介绍需要按具体行为判断，不能自动套用中立技术服务的结论。[条例](https://www.cac.gov.cn/2013-02/08/c_126468776.htm)
- 原标题、元数据和介绍也需按实际内容、表达与使用方式判断。“标题＋链接”不是对所有标题和编排的无条件许可。原创短介绍更易控制使用范围，但短并不自动合法。
- 《著作权法》第二十四条的适当引用有目的和使用边界，注明出处只是条件之一；法律没有给网站摘要设定统一安全字数。[著作权法](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)
- RSS、官网摘要和开放 API 能公开读取，不自动代表可以复制、再发布或上传模型。仍核对具体许可与条款。开放获取论文也需要逐项看许可条件。
- 本项目是医疗相关资料导航，不能直接沿用粘贴材料中关于技术博客的行业判断。内容的实际性质、主体和渠道需要另行核实。

“手动录入”是当前产品选择，不是著作权免责条款；“只是导航”“免费”“仅供参考”都不能替代实际内容与运营边界。

## 3. 来源处理规则

| 资料情形 | 当前处理 |
| --- | --- |
| 合法机构或作者公开页面 | 核对后收录必要题录、独立介绍和原站入口；不默认复制正文 |
| 期刊、数据库登录或付费页 | 可核实题录与合法入口，如实提示访问条件；不绕过限制 |
| 有明确开放许可的作品 | 记录许可版本、链接和条件；具体复制、翻译或再发布逐项判断 |
| 公开家庭经历 | 优先原作者入口，避免搬运照片、诊疗记录及儿童识别信息；站内全文需另核实授权与隐私 |
| 第三方网站或付费代下论文 | 来源和授权未明前不上传公开站或第三方知识库，优先另找合法题录页面 |
| 盗版、破解、付费墙绕过或不明镜像 | 不收录此类阅读/下载入口，发现后停用并核查 |

论文摘要、译文、截图、图表与图片都有各自的权利问题，不因附有 DOI 或原文链接而免除。原站内容更新、撤稿或来源被查明有问题时，站内介绍也应复核。

## 4. 投诉和更正

建立真实可用的联系方式、资料定位信息、处理记录与恢复依据。涉及涉嫌侵权或隐私的内容优先暂停公开，按通知材料和具体事实处理，不承诺“收到投诉仍维持链接”。

条例第十四条起规定通知、断链和相应程序，具体适用依实际服务关系判断。个人编辑站不应机械套用存在“上传用户”的全部流程；必要时取得个案法律意见。[条例](https://www.cac.gov.cn/2013-02/08/c_126468776.htm)

联系方式不要求访客提交病历或儿童身份证明。必要处理材料留在内部，不公开展示投诉人个人资料。

## 5. 医疗内容与主体

运营者如实以资料整理者身份展示，不自称医生、医院、医学审查团队。原文是机构发布并不表示本站与机构合作，也不表示本站获得背书。

短介绍尽量说明材料主题、来源和背景，不编写个体诊断、检查选择、妊娠决定和治疗建议。若实际业务扩展为专业科普或咨询，需要重新核实相应内容与渠道条件；不能依靠更名或免责声明解决。[医疗科普相关通知](https://www.cac.gov.cn/2025-08/01/c_1755764425442686.htm)

网站备案、微信小程序类目及发布审核分别处理。个人备案的真实所在地仍未提供；面向全国不等于全国是备案属地。小程序技术接口存在，不代表个人主体及该内容主题已经通过审核。

## 6. 公众 RAG 的后续条件

当前不需要采购腾讯知识库。将来重新评估时，先确认实际用户需求，再分别核实材料上传与索引权利、个人账号和发布条件、输出范围、专业内容安排、应用登记与标识、用户输入与费用控制。

腾讯托管减少工程建设，不接管运营者的全部责任。ADP 条款对专业咨询、内容权利及客户责任有独立约定，不能以模型备案或采购套餐替代项目条件。[ADP 条款](https://cloud.tencent.com/document/product/301/104939/)

当前资料卡能公开，并不意味着对应原文能进入 RAG。后续若只索引自写介绍，能力也只是帮助找本站资料，不能宣传成“已理解并核对全部论文全文”。

没有完成逐篇资料版权审计、监管确认、平台正式答复或专业医疗审核。当前不引用没有核实全文的反不正当竞争法条款作为本项目已经违法或已经免责的依据；首版本来也不开展自动批量采集。
