# 弯弯：产品需求与内容规范

版本：5.0｜2026-11-12｜当前需求基线，尚未实现。

配套：[项目计划书](./项目计划书.md)｜[技术架构与实施方案](./技术架构与实施方案.md)｜[个人运营与版权边界](./个人运营与版权边界.md)。

## 1. 首版边界

手动精选的足内翻相关知识导航，服务孕妇及家庭。Web 和微信原生小程序共用资料，保留 Spring Boot，使用 Halo 后台。当前只更新方案，不进行开发或公开发布。

资料卡是首要对象：必要标题和来源、自写简短介绍、阶段与类型、原文入口、核对日期。第三方正文、原文配图和论文摘要不默认保存。本站原创导读是第二类对象，不与第三方材料混写。

访客无需注册。首版不开放用户投稿、论坛、评论、私信、报告上传、个体医学判断和公众 RAG。平台未要求登录也不代表访问日志没有个人信息，应按最小必要原则处理。

## 2. 信息架构

| 页面 | 内容与行为 |
| --- | --- |
| 首页 | 简短定位、阶段入口、精选专题、站内搜索；不使用诊断问卷决定入口 |
| 阶段页 | 阶段导读、按人工顺序排列的资料卡、类型和主题筛选 |
| 专题页 | 运营者维护的阅读顺序、适用背景、相关资料 |
| 资料列表 | 标题、来源、类型、简短介绍、核对日期；清楚区分来源发布日期 |
| 资料详情 | 完整来源信息、自写介绍、阅读背景、可用的原文入口、相关资料与反馈入口 |
| 本站原创 | 自写导读或使用说明，明确作者、日期和真实来源；专业内容按实际条件审核 |
| 搜索 | 只查已发布题录、介绍、标签及允许公开的原创文字 |
| 关于与规则 | 运营者身份、收录方法、版权勘误联系方式、隐私说明、维护状态 |

阶段固定为“刚发现、产前了解与等待、出生后评估与治疗、支具与日常生活、长期随访与预后”。一条资料允许关联多个阶段，专题可跨阶段。主题标签应受控维护，避免产生大量近义标签。

首版不设置“最好医生”“最佳治疗”“适用于你的方案”等排序。精选排序只表示编辑安排的阅读顺序。

## 3. 资料卡字段

| 字段 | 要求 |
| --- | --- |
| 稳定 ID、条目类型、状态、版本 | 系统维护；条目类型区分外部资料与本站原创 |
| 原标题、显示标题 | 默认保留原标题；必要的中文辅助标题标为本站拟写，不改变原文含义 |
| 原始 URL | 指向合法来源页面；不填写盗版下载、代下服务、绕过访问限制的地址 |
| 作者或机构、来源站名 | 能核实的如实填写；无法确认标明未知，不用 AI 补猜 |
| 原文发布日期、最后核对日期 | 分开保存；原文无日期时显示未注明 |
| 独立介绍 | 运营者自己撰写的主题、背景及阅读提示，不复制原文摘要 |
| 阶段、材料类型、主题标签 | 阶段可多选；材料类型为机构资料、论文题录、家庭经历、本站原创 |
| 语言与访问条件 | 中文/其他；公开可读、需要登录、可能付费或未确认 |
| 论文标识 | 适用时填写 DOI、PMID 等可核对标识；不因此提供全文下载 |
| 经历背景 | 适用时记录故事发生或随访时点；仅保存原作者已合法公开且收录必要的信息 |
| 链接与内容状态 | 未核对、正常、需复核、原文撤回、已停用；与发布状态分开 |
| 内部记录 | 收录理由、许可与取得依据、核对记录、投诉处理；不向公众输出 |

自写介绍建议一至三句，讲清材料讨论什么及阅读背景；这是编辑规范，不是法律规定的安全字数。不得将研究结果改写成对读者个人的结论，也不以“读了本站介绍就不必读原文”为目标。

图片为可选。默认用自制类型图标或无图布局，不自动提取封面、公众号图片、医院标识或论文图表。

## 4. 手动收录流程

```mermaid
flowchart LR
  Candidate[发现候选来源] --> Verify[核对原站与内容]
  Verify --> Draft[手动录入题录与自写介绍]
  Draft --> Preview[分类去重与双端预览]
  Preview --> Check[确认来源和公开范围]
  Check --> Publish[发布资料卡]
  Publish --> Review[定期复核与处理反馈]
  Review --> Update[修订或停用]
```

运营者逐篇查看真实原文，不凭搜索摘要或 AI 输出完成收录。不能确认正文时，只能记录已核实的题录及访问限制，不写未经核实的内容介绍。

先核对来源机构和原作者，再核对链接是否指向正确版本。机构、论文与家庭经历各自采用不同背景说明，不能把第三方转载自动当成官方发布。

不自动从 URL 抓取正文、标题或封面。小范围录入也需要去重与版本记录，不能将复制整段原文当作“手动录入”的允许行为。

## 5. 双端交互

Web 支持按阶段浏览、类型筛选、关键词搜索、资料详情和普通外部链接。外部链接明确显示来源，不使用 iframe 或正文代理伪装本站内容；原文要求登录或付费时如实提示。

小程序列表与详情展示同一份公开信息。来源入口按能力区分：经核实可使用的公众号文章入口、其他小程序入口、外部网页及仅能显示出处的材料。不得用统一按钮暗示所有材料均可在小程序内直接阅读。

无法直接打开时，至少保留完整题名、来源、日期和可靠标识。复制来源信息或链接可作为待验证交互，必须清楚告知操作结果，不视为绕过外链限制或保证过审的方案。

无内容、加载失败、失效链接、资料撤回分别有明确状态。显示“原文目前不可访问，稍后复核”，不能自动寻找不明镜像补链。原文撤稿的资料暂停正常推荐，是否保留撤稿提示由编辑核查后决定。

## 6. 搜索与推荐

只索引当前已发布且允许公开的资料字段与原创内容。搜索题录不要求下载原论文。内部许可记录、反馈邮件、管理日志和隐藏草稿均不参与搜索。

支持标题与介绍关键词、阶段、类型筛选；空结果提供相关阶段和调整关键词提示，不调用模型编造答复。中文分词、别名与排序效果在小样阶段验证，不能先承诺完整语义理解。

相关资料采用人工关联或共同标签规则，不根据读者健康档案推断需求。后续若加入语义搜索，需要重新检查查询数据处理与索引范围。

## 7. 撤回、纠错与投诉

网站必须设置真实可用的版权、勘误联系渠道，地址由运营者提供，不能写虚构邮箱。小程序在关于页显示对应联系办法。

收到涉嫌侵权、隐私泄露、明显错误或危险来源的反馈时，先暂停受影响公开内容或链接，再核查来源与通知材料，记录处理结果。恢复需有核实依据。具体法律程序按实际情形处理，不能仅以“我们只放链接”拒绝。

停用资料必须从列表、专题、搜索、站点地图和相关资料中移除，旧详情 URL 不继续展示原有内容。Web 与小程序的服务端读请求执行同一规则。本机收藏再次打开时重新确认状态；离线设备已经保存的信息无法保证即时撤销，对外不承诺远程抹除。

## 8. 验收情境

| 编号 | 情境 | 通过标准 |
| --- | --- | --- |
| P01 | 访客从首页选择阶段 | 可以找到对应资料，来源类型清楚，不强迫填写健康信息 |
| P02 | 运营者录入外部资料 | 可完成题录、自写介绍、分类、预览与发布；无需抓取全文 |
| P03 | 搜索相关主题 | 只返回允许公开的内容，内部备注和草稿不出现 |
| P04 | Web 阅读原文 | 直接进入正确原站，登录或付费条件有说明 |
| P05 | 小程序来源入口不可用 | 页面如实说明并提供可核对出处，不出现假成功或空白页 |
| P06 | 资料下线 | 双端在线请求、专题和搜索均停止返回，旧链接得到下线状态 |
| P07 | 原文失效或撤回 | 标记、停止正常推荐并核查，不自动替换盗版来源 |
| P08 | 版权或隐私反馈 | 联系渠道可用、处置有记录、内部材料不公开 |
| P09 | 无数据或服务故障 | 有空状态或错误提示，既不造资料也不触发 AI |
| P10 | 恢复备份 | 能恢复资料、状态、原创素材与必要配置，撤回记录得到保留 |

以上为未来验收要求，不是已完成测试。

## 9. 后续功能的进入条件

收藏同步需要账号与数据处理方案；读者投稿需要授权、去标识和审核；公众 RAG 需要独立需求、许可语料、腾讯平台条件及实际公开服务路径。三者均不因当前保留字段而默认进入首版开发。
