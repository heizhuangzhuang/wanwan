# 弯弯产品需求与内容规范

更新于 2026-11-19。本轮小程序状态按当前开发分支记录，实施顺序见[开发计划](./项目计划书.md)。

## 1. 产品范围

面向产前发现胎儿疑似足内翻的孕妇及家庭，由个人整理可核对的出处。访客无需登录即可阅读和搜索。Web 优先交付，公众号手动分发，小程序在二期复用同一套公开资料与撤回规则。

首版只做知识导航、资料检索和编辑维护。用户投稿、论坛、评论、私信、报告上传、家庭健康档案、个体医学判断与公众 RAG 均在范围之外。

## 3. 阶段与资料卡

| 阅读阶段 | 收录内容 |
| --- | --- |
| 刚发现 | 入门出处、术语、站点使用说明 |
| 产前了解与等待 | 机构资料、研究题录和注明背景的家庭经历 |
| 出生后评估与治疗 | 机构公开资料、治疗流程的出处与家庭经历 |
| 支具与日常生活 | 支具、复查、照护和生活资料入口 |
| 长期随访与预后 | 随访资料、研究题录与注明观察时间的家庭经历 |

一条资料可归入多个阶段；专题可跨阶段，由运营者排列阅读顺序。资料类型统一为机构资料、论文题录、家庭经历和本站原创，专题与相关推荐使用同一套受控标签和公开状态。编辑顺序表达阅读组织，页面避免以诊疗效果或医生优劣排序。

| 信息 | 录入与展示要求 |
| --- | --- |
| 题名与来源 | 保存原标题、来源站、作者或机构、合法原始 URL。辅助标题标明为本站拟写，未知信息如实注明 |
| 日期与访问 | 原文发布日期和本站最后核对日期分开。记录语言及公开、登录、付费或未确认等访问条件 |
| 独立介绍 | 自写一至三句说明材料主题和背景；保留原文入口。论文摘要、正文和原文配图默认由原站承载 |
| 编目 | 多选阶段、单选类型、受控标签与人工顺序；适用时记录 DOI、PMID 或家庭经历的发生/随访时点 |
| 状态与入口 | 发布状态和来源状态分开。来源未核对时保留出处，正常入口需由运营者确认后开放 |
| 私有记录 | 记录收录理由、许可依据、核对过程、投诉处理和恢复依据，以资料卡 ID 关联，留在私有台账 |

## 4. 编辑到发布

1. 查看来源原页，核对来源身份、访问条件和材料版本。只能确认题录时，按已核实的信息编目。
2. 手动录入资料，撰写介绍，选择阶段、类型和标签，检查重复 URL、DOI 或 PMID。展示相似记录供编辑判断。
3. 预览 Web 和小程序的公开字段、出处和降级说明，确认核对日期与可公开范围后发布。编辑已发布资料时，确认保存之前仍展示现行公开版。小程序未接正式环境时，可用后台预览验证展示内容。
4. 对失效、疑似侵权、隐私问题或错误来源，按影响先暂停链接或资料，核查后记录处理和恢复依据。原文撤回时移出列表、专题和搜索，是否保留带提示的题录详情由编辑判断。

## 5. 公开体验

- Web 原文入口直达已核对的来源站；访问条件在点击前可见。相关推荐可由编辑关联或按共同标签选取，仅展示有效公开资料。
- 小程序按实际支持情况展示公众号文章、其他小程序或出处信息。跳转失败时明确反馈并保留题名、来源、日期和可靠标识。复制成功与失败分别提示。
- 无内容、请求失败、来源失效、原文撤回、本站下线分别显示状态。本站撤回后，列表、专题、搜索、站点地图和相关资料停止展示，详情返回下线状态，专题公开计数同步更新。
- 关键词搜索仅查公开资料内容。无结果时可调整关键词或改按阶段浏览，结果页仍可使用阶段和类型筛选。原创文章正文是否纳入搜索需按后续决策执行。
- 关于页提供运营者真实身份、收录规则、隐私和维护说明及版权勘误联系方式。反馈渠道以资料名称或链接定位条目。

## 6. 验收情境

| 编号 | 情境 | 通过标准 |
| --- | --- | --- |
| P01 | 从首页按阶段找资料 | 可区分来源类型，找到阶段、专题及资料详情；筛选翻页保留条件 |
| P02 | 运营者录入并发布 | 走通核对、查重、预览和发布，能识别尚未确认的来源 |
| P03 | 搜索相关主题 | 公布的命中范围与实际一致；支持阶段与类型筛选；草稿和内部记录不会出现 |
| P04 | Web 阅读原文 | 跳转至核对过的原站；登录、付费等条件有提示 |
| P05 | 小程序原文入口不可用 | 显示可核对出处；跳转失败与复制结果提示准确 |
| P06 | 本站撤回资料 | Web 和已接入的小程序在重新请求后停止展示；旧详情、专题、搜索、站点地图、相关资料符合撤回规则 |
| P07 | 原文失效或撤回 | 暂停对应入口；原文撤回移出推荐；按处理结果决定是否保留带提示的题录 |
| P08 | 版权或隐私反馈 | 联系方式经验证；运营者能定位、暂停并记录处理；私有台账与投诉材料不公开 |
| P09 | 无资料或后端失败 | 空状态、请求失败与下线可区分，故障恢复后可重试 |
| P10 | 从备份恢复 | 在隔离环境恢复数据、原创素材和必要配置；恢复历史撤回状态后才对外开放 |
