# 支具长期随访

## 每天记录，按年复盘

家长平时在小程序穿戴页计时或补记，复诊前打开随访大屏。小程序适合手边记录，Web 适合在电脑上同时查看趋势、计划和明细。两个页面共享统计逻辑和备份格式。用户可查看 7 天、30 天、90 天、1 年、10 年或全部历史，也可选择过去的截止日。

目标按生效日保存，跨阶段调整只影响新计划覆盖的日期。到了仅复查随访的阶段，可以记录复诊和调整支具的日期及备注。十年是档案和回顾窗口。医生决定穿戴时间、阶段安排和是否结束穿戴。 [美国儿科学会临床报告](https://publications.aap.org/pediatrics/article/149/2/e2021055555/184569/) [爱荷华大学 Ponseti 家长指南](https://ponseti.medicine.uiowa.edu/parent-information/bracing-tips)

## 大屏提示的含义

| 显示 | 统计规则 |
| --- | --- |
| 记录低于目标 | 已结束的计划日有穿戴时段，去重累计低于该日目标。可能需要补记 |
| 计划日无记录 | 已结束的计划日缺少穿戴时段和未穿确认 |
| 确认未穿 | 家长单独确认过去某日未穿，该日无穿戴时段 |
| 仅随访 | 医生安排进入复查阶段，日期仍可保留穿戴或随访记录，不累计计划日缺口 |
| 今日进行中 | 显示已记录时长，待日期结束后再归类 |

月、年柱图为有记录日平均时间，确认未穿计 0，无记录日从均值分母排除。按使用设备的本地日历切分跨午夜时段，重叠时段只计一次。记录用来发现需要补记或跟医生沟通的情况。研究中佩戴依从性与复发相关，但家庭手记、复发定义及随访人群存在差异，临床风险由医生结合检查评估。 [5–10 年原始随访研究](https://pubmed.ncbi.nlm.nih.gov/35081931/) [传感器与家长记录对照研究](https://pubmed.ncbi.nlm.nih.gov/27707845/)

## 文件与持久化

- 小程序用两个本机文件交替写入。写完下一份后才更新指针，保留旧版记录的迁移路径。Web 用浏览器 IndexedDB。
- JSON 是完整档案，可在另一个设备或 Web 恢复。恢复前显示时段数并要求确认替换。同步由用户主动传输备份文件完成。
- Excel 导出所选区间，包含概览、每日统计、穿戴时段、计划历史和随访记录。无记录单元格留空，确认未穿填数值 0。计划历史展示完整生效时间表，方便追溯区间首日适用的目标。
- 数据保存在当前设备。长期留存依赖定期备份。Web 地址为「家庭工具 → 支具随访大屏」，页面本身不依赖 Halo 资料接口。

## 验收

跨夜、重叠区间、当日未结束、计划生效切换、仅随访、已确认未穿和漏记需得到不同结果。用十年样本验证聚合、JSON 往返和 Excel 打开。两端分别验证备份恢复和本地持久化，手机端还需核对微信文件分享和实际接收。
