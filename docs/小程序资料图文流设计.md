# 小程序资料图文流设计

日期：2026-11-23

## 目标与范围

让刚遇到胎儿超声疑似足内翻的家长，在资料页顺着阅读，先判断一篇内容是否有帮助，再进入完整文章。沿用首页、资料、工具、我的四个栏目。

本轮仅重做资料页下方的内容呈现。搜索框、阶段筛选、进入阶段专区链接与产前检查专项的结构和样式保持原样。阅读模式借鉴知乎的标题与摘要层次、微博的单列图文连续浏览，发布主体与内容仍由本站运营者管理。

参考入口：[知乎官方应用页](https://apps.apple.com/cn/app/id432274380)、[微博官方应用页](https://apps.apple.com/cn/app/id350962117)、[Halo 文章管理](https://docs.halo.run/guide/use/posts)。这些入口用于产品参考；下面的具体布局与交互是本项目的设计选择。

## 头部阅读目录

原先位于底部的「按形态浏览」移到阅读流标题右侧，入口命名为「阅读目录」，默认收起。点开后在标题下方展开三行：原创导读、资料卡、阅读专题；有精选专题时附在面板下方。展开状态使用浅绿色背景和向上箭头反馈。

面板为页面内的折叠区域，不遮挡正文、不新增全屏菜单。点击目录入口后先收起，再进入对应页面；切换阶段也会收起。阶段已选时，前两项直接进入本阶段的导读和资料卡，专题入口仍浏览主题合集。原底部大目录删除，避免重复。

## 内容层次

每条内容自上而下展示：

1. 实际来源或公开作者、内容类型、文章发布日期。
2. 完整标题，不横向滚动，不截断重要词语。
3. 正文介绍，默认最多四行；较长摘要允许原地展开与收起。
4. 可选的文章封面，点击预览完整图片，加载失败回退为文字。
5. 适用时显示期刊与年份，避免将文献出处堆入摘要。
6. 阅读全文或查看资料出处，以及分享给家人。

采用单列，每两篇文章穿插一张资料卡，分别保留后台文章时间顺序和资料的编辑顺序。加载后续批次时只向尾部追加，避免读到一半改变前面的位置。没有封面的文章采用完整的文字版式。

## 视觉规范

- 场景：阅读；风格：温和的编辑式排版。
- 沿用页面背景 `#FBF7F0`、内容底色 `#FFFDF9`、主色 `#376052`；标题 `#24362C`，摘要 `#475145`。
- 信息流标题使用「PingFang SC / Microsoft YaHei」34rpx，正文29rpx、1.8倍行高；来源25rpx，辅助信息22–24rpx。
- 左右间距沿用页面28rpx，条目内部26rpx；不新增自定义顶栏或浮层挡住阅读。
- 每条分隔使用浅色留白带；预览配图占满正文宽度，缩略图点击后可查看原图。
- 阅读、展开与分享的点击区域至少44px高。阅读目录按钮同样保持44px最小点击高度。

## 接口与图片

继续使用已有 `posts`、`stage-posts`、`resources`、`topics` API，不新增聚合后端服务。`PostSummary` 与 `PostView` 增加可选 `coverUrl`，取自已公开文章的 Halo 封面设置。Web 类型声明同步增加该字段，已有字段保持兼容。

首屏与追加分别拉取5篇文章、3张资料卡，两条分页游标独立推进。单路失败不能推进失败游标，也不能删除已加载内容。文章详情仍读取已发布快照，不使用编辑中的草稿。

封面与正文仅显示符合规则的绝对 HTTPS 栅格图片；不自动搜图、热链来源文章配图或补画医学示意图。上传与发布图片的权利由运营者核对。相对路径、SVG、内嵌凭据、不支持的协议不进入小程序配图。后端未升级或文章未设封面时，使用文字流。

## 阅读与返回

从流进入文章附带 `mode=full`，默认展开全部章节；用户仍可使用目录或折叠章节。返回资料页保留已加载批次和摘要展开状态，同时重查这些批次的公开可见性。被撤回的内容移除，未撤回内容保持相对顺序。

下拉刷新从第一页重新加载；切换阶段立即清空内容，并丢弃旧阶段未完成的响应。文章与资料卡使用不同前缀的唯一标识，名称相同也不会互相覆盖。

## 验收

- 搜索、阶段筛选与产前专项与修改前逐字比对，样式不变；新增的阅读目录默认收起，展开、导航与阶段路径可用。
- 纯文字、封面图、长标题、展开摘要、坏图回退与分享入口均可使用。
- 追加失败、重复触底、快速切阶段、返回重查、撤回内容不产生旧数据串入。
- 普通文章入口维持分节阅读；信息流入口支持连续全文阅读。
- 小程序 TypeScript 与公开流程测试、后端 DTO/公开接口测试通过；在微信开发者工具检查实际布局与跳转。

真机仍需覆盖 iOS、Android 的图片访问、微信分享和弱网追加；模拟器不能代替正式环境验收。

## 版本与交付

后端版本0.1.7增加可选封面字段。小程序文字流兼容旧后端；封面读取需部署新版后端并在 Halo 中为文章设置有效图片。后端插件升级包由当前源码构建，生产服务未在本轮自动替换。在现有环境中优先通过 Halo 控制台升级 JAR。单版本云托管压缩包适用于新环境；已有环境若需要重建镜像，须按部署文档加入登记版本对应的旧版 JAR，不能直接用单版本包替换已有兼容包。

## 本轮验证结果

- 小程序：TypeScript 编译与61项公开流程测试通过。
- 后端：61项测试通过，0.1.7插件构建成功。
- Web：类型检查、构建与29项测试通过。
- 微信开发者工具：检查目录收起与展开、点击导航、44px触摸区域，以及阅读流进入全文模式。配图版式另用明确标注的临时界面数据核验，之后恢复真实 API 内容，未向后台写入测试文章。
- 搜索、阶段筛选、产前专项的模板和样式与原版逐字比较一致。
