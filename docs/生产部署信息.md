| 管理对象 | 所需账号或授权 | 建议的私有凭据条目 | 在哪里核对 |

| 微信云托管 | 有权限查看版本、日志、环境变量的微信账号 | `Wanwan / 生产 / 微信云托管` | `xiaojiaoya` 服务及其权限管理 |

私有条目建议记录实际地址、账号、凭据、负责人、最近核对日期和轮换记录。生产发布后核对当前流量版本、Web 健康状态，以及 Web 与小程序查询同一批公开资料的结果。密码轮换时更新私有条目和服务运行配置，再验收连接。
