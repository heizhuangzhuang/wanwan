# 小脚丫步步指南开发计划

更新于 2026-11-20。

小脚丫步步指南是个人维护的足内翻家庭指南。小程序帮助家庭从产前超声初次提示走到出生后的治疗、支具照护与长期随访，每阶段都能找到就诊准备、工具和对应的公开资料。运营者逐条核对并手动录入出处，公众号由运营者手动分发。

功能范围和验收用例见[产品需求与内容规范](./产品需求与内容规范.md)，实现方式见[技术架构与实施方案](./技术架构与实施方案.md)，收录和投诉处理依据见[个人运营与版权边界](./个人运营与版权边界.md)。

## 当前进度

- 已有 Halo 资料卡和专题后台、公开查询 API、资料卡关键词搜索、独立 Web SSR 页面、小程序公开浏览、专题与原创导读落地页和部署模板。
- 本地覆盖公开资料、撤回、服务重定向、编辑查重与小程序订阅流程。CI 与 Dockerfile 均使用锁文件构建，CI 固定 pnpm 9.15.9 并在构建 Console 后打包插件。
- [首批真实资料](../content/README.md)已在本地 Halo 验证导入、去重和公开检索。生产内容录入、Halo/MySQL/Web 全链路验收、备份恢复和小程序真机与提审仍待完成。

## 原交付顺序

| 阶段 | 交付内容 | 完成条件 |

| 2. Web 首版 | 完善编辑核对、Web 筛选与翻页、阶段导读、相关资料、反馈处理和首批内容 | 产品验收 P01–P04、P06–P09 的 Web 场景通过。首批以约 20–30 条核对资料为编辑目标，覆盖五个阶段，缺少资料时显示空状态 |
| 3. 上线准备与发布 | 生产部署、公开访问与管理入口隔离、真实联系方式、备份恢复、Web 发布条件确认、公众号手动发布 | 实际生产链路通过冒烟检查；P10 恢复演练通过；域名、HTTPS、备案和联系方式记录齐备；公众号首发按账号实际能力执行 |

两端按自身发布条件分别验收。小程序能力核实可与 Web 开发并行。主体或类目不适用时，保留 Web 和公众号，是否调整主体由运营者决定。

## 2026-11-20 小程序优先改版

本轮先交付小程序阅读体验，Web 同步公开检索能力。公众号专题、导读及单条资料的既有落地链接继续使用。公共内容统一由 Halo 提供，首批资料与专题仍由运营者逐条核对发布。

| 工作项 | 本轮代码 | 接手验收 |
| --- | --- | --- |
| 首页与浏览 | 暖色阅读首页、五阶段导读、资料库入口、专题预览、精选资料、错误与空状态 | 真实内容到位后核验每阶段的目录覆盖和出处 |
| 资料检索与回访 | 小程序快捷词和筛选，详情显示相关阅读；本机阅读夹提供收藏与最近阅读 | 核验重启后仍能查看列表。资料本站撤回或原文撤回后，阅读夹重新校验时停止显示 |
| 就诊沟通 | 可勾选和复制通用问题清单 | 清单只有固定问题，填写诊疗信息、保存就诊时间和发送提醒属于后续私人功能 |
| 双端公开 API | Web 补阶段标签筛选、搜索筛选与保留条件的分页；双端使用相同资料接口，专题数量与详情复用同一可见性规则 | 使用实际云服务检查发布和撤回后，两端结果和专题数量一致 |
| 编辑与勘误 | Console 发布前查重与预览，Web 和小程序显示导读署名并支持带资料编号的勘误入口 | 核实真实署名、联系邮箱、编辑核对和勘误处理流程 |
| 微信新资料通知 | 首页一次性订阅、取消待发、首次公开时保存发布事件、发送前检查当前可见性 | 配置实际账号可用模板，体验版真机验证收到消息并打开来源详情 |
| 还待联调 | 生产匿名资料接口、首批内容、公众号跳转、真机验收和备份恢复 | 匿名接口必须返回 JSON 再联调 Web 和小程序；完成真实账号的 P05–P10 相关验收 |

阅读夹只存资料标识在本机，列表打开时重新向公开接口查询。2026-11-20 的家庭工具变更增加了云端石膏记录、同微信账户换机恢复和独立的复诊提醒，生产默认关闭并从体验版验收。

## 上线后如何判断效果

用少量真实读者的反馈检查能否找到对应阶段的资料、识别来源类型并顺利到达原站。运营者记录核对每条资料的时间、失效链接、勘误和撤回情况。项目按个人免费资料站运营，运行成本以实际云资源、域名、备份和编辑时间核算。

公众 RAG、收藏同步、投稿、论坛、报告上传与个体诊疗服务均在首版范围之外。公众 RAG 如需推进，单独确认需求、语料权利和上线条件。

2026-11-19 用户确认本轮交付公开浏览和公众号文章落地页。已确认的云端石膏记录、家长手填事项和下次治疗时间、微信提醒保留为后续私人功能。

## 家庭工具与产前专项验收

- 沿现有五个阶段阅读时，家长能找到此阶段要准备的材料和问题，从「工具」查就诊渠道、机构与医生科普及家长经验。好大夫和医院入口供查找科室，小红书和抖音使用用户主动复制的搜索词，并列出已核对的账号出处。真机核验查找和复制流程。
- 小程序与 Web 分别提供独立入口。产前专项首批覆盖结构超声、血清筛查与无创 DNA、羊水穿刺、染色体核型与微阵列、全外显子测序、遗传咨询。公开内容可在资料后端故障时浏览。
- 石膏记录由监护人按医院交代填写。云端按微信账户隔离，单独同意后保存，支持修改、逐条删除和撤回清除。复诊消息使用单独模板、单次授权，只发送通用标题和时间。
- 本地通过后，在新云托管插件和持久化 MySQL 上先验收公开接口。私人记录先用虚构数据做账户隔离、备份与恢复、撤回；再核实隐私声明和微信模板，体验版验证真机送达。
