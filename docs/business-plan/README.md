## 文档范围

从孕期超声提示足内翻开始，覆盖复核与产前评估、检查选择、羊穿流程、分项等待及报告解读、按需多学科咨询、分娩交接、新生儿评估、矫形治疗、支具及长期随访。包含情绪支持、异地就医、暂停服务和不同妊娠结局的路径。

现有软件设计参考、医学依据及监管来源均在计划书中列出。拟议方案、已有依据和待验证事项按文内说明区分；文档未载入原始私人病历。
