# 小脚丫家庭记录双端登录需求

2026-11-25 · 产品方案，待开发验收。适用于访客 Web 和微信小程序。

实施入口见[双端开发设计](./家庭记录双端开发设计.md)及[测试用例与放行条件](./家庭记录双端测试设计.md)。

## 1. 哪一步需要登录

家长可能只想查资料，也可能已经开始为孩子记录治疗过程。登录提示放在第一次访问私人数据或操作记录时。两类工具免费，工具介绍和操作说明对所有人开放。

| 家长的操作 | 未登录时的体验 |
| --- | --- |
| 从首页、搜索、分享或公众号进入文章、专题、石膏或支具使用说明，下载公开清单 | 直接阅读、搜索、下载，全程无登录弹窗 |
| 打开「工具」或「我的」，使用现有本地阅读夹、通用沟通清单 | 正常使用。只在主动打开私人记录时提示登录 |
| 点「记一次石膏」「查看我的石膏记录」或从复诊提醒直达某条记录 | 在显示个人数据或进入编辑前登录，完成后回到原目标 |
| 点「开始佩戴计时」「补记一段」或查看个人佩戴历史、统计、导出 | 登录后回到对应操作。统计与导出的权限跟随所属档案 |

## 2. 家长从哪里来，就回到哪里

- 小程序展示「用微信登录」和「暂不登录」。Web 电脑端展示临时小程序码，家长扫码，在手机核对并确认本次网页登录。同一手机浏览 Web 时可切到小程序输入一次性配对码。取消或超时都可返回原页继续阅读。
- 两端关联同一个 Halo 普通用户，各自保持登录。已有有效会话直接使用。访客不需要填写本站密码、手机号或孩子姓名。服务端记录本次从 Web 或小程序登录，家长没有管理后台权限。
- 界面按当前任务解释用途。石膏入口显示“登录后可保存换石膏日期和复诊安排”；计时入口显示“登录后可换设备继续计时，查看已同步的佩戴记录”。
- 首次云端保存时，请监护人确认对应工具保存的数据、用途及删除入口。登录与保存授权分开，已有有效授权沿用。拒绝后仍可阅读所有公开内容。微信提醒另行订阅，拒绝提醒也能记石膏。
- 登录完成后回到原按钮或草稿。计时页展示当前状态，由家长点击「开始计时」才记起点，扫码、等待授权的时间不算佩戴时间。

## 3. 两个需要跨设备完成的任务

**石膏记录。** 家长按医院交代填写换石膏日期、注意事项和下次复诊时间。保存得到服务端确认后，两端重新打开或刷新即可看到同一条记录。保存失败保留当前输入，重试只产生一条。改期或删除会取消尚未投递的旧提醒；改期后可在小程序重新订阅新日期。已经进入投递的提醒应显示实际发送状态。

**矫正器计时。** 每份档案同时最多一段进行中的计时。小程序开始，关闭小程序后计时继续；电脑打开显示同一个起点，可在电脑结束。后台按开始和结束时间计算，跨午夜可分日统计并保留完整时段。两端同时开始、结束或补传，后台只确认一次有效操作；遇到矛盾的时间，请家长核对。

**同步反馈。** 已登录、已授权的设备在断网时，将操作保存为该账号的本机待同步记录，提示“仅保存在这台设备，联网后同步”。本机写入失败时保留当前输入并提示重试。只有服务端确认后才显示“已同步”。待传期间退出或切换账号前说明影响，原账号的草稿和待传记录只向原账号恢复。新设备只能恢复已同步记录。

## 4. 存量用户和运营

小程序石膏记录已有微信身份和加密云存储；小程序支具工具已有本地记录及手动整档备份；Web 支具工具使用浏览器本地存储。实施时先验证微信身份，再关联原有云端数据。不得因首次创建 Halo 用户而初始化覆盖旧档案。

对设备上未绑定账号的旧记录，先展示记录数、日期范围和是否有进行中的计时，由家长确认归属、选择导入，也可跳过或导出旧备份。同一批次重复导入不增加记录；与云端时间重叠的条目单独核对。首次登录不自动上传共享设备上的历史。上线前为已开启的旧计时保留原始开始时间和恢复入口。

Halo 管理员可停用账号、撤销会话、按记录编号排查同步结果。一般运营视图只显示同步时间和结果。家长可导出、删除自己的记录。上线需具备云端备份，并在隔离环境完成一次恢复验证。

## 5. 上线验收

| 场景 | 通过条件 |
| --- | --- |
| 无账号读者从公众号或分享进入，在两端读文章、搜资料、下清单；登录服务临时不可用 | 公开内容服务正常时，上述路径始终可用 |
| 首次点击记录工具，分别测试取消扫码、二维码过期、拒绝云存储和成功登录 | 取消可继续阅读；成功返回原操作；未确认开始不产生计时 |
| 同一微信换机或在 Web 登录，读取旧石膏记录、手动备份和新记录 | 找到原档案；两个不同用户互相不能查看、修改或导出记录 |
| 小程序开始计时并关闭，跨午夜在 Web 结束，两端同时点结束 | 起止一致，时段只保存一次，分日合计等于该时段总时长 |
| 断网保存、关闭重开、重新联网、重复提交、再换设备 | 兑现本机或云端状态提示；补传成功后新设备可见且无重复 |
| 同一设备切换账号、重复导入旧记录、两端同时修改同一条 | 无跨账号展示或上传；无重复导入；有冲突时保留两个版本供核对 |

建议按“身份关联及旧档案只读核对 → 两端写入和计时同步 → 弱网、隔离和恢复验收”交付。验收通过后再切换现有工具入口。
