# ADR-004：公开接口与微信渠道

状态：已采纳｜日期：2026-11-17

## 公开 API
前缀 `/apis/api.wanwan.run/v1alpha1`，匿名可读，只返回白名单 DTO：

| 接口 | 说明 |
| --- | --- |
| `GET /stages` | 5 个固定阶段 |
| `GET /resources?stage=&type=&tag=&page=&size=` | 已发布资料卡分页 |
| `GET /resources/{name}` | 资料卡详情；未发布/已停用统一返回 404 |
| `GET /topics`、`GET /topics/{name}` | 已发布专题，内含资料卡只保留已发布项 |
| `GET /posts`、`GET /posts/{name}` | 已公开原创导读，详情读取发布快照 |
| `GET /search?keyword=&stage=&type=&page=&size=` | 见 ADR-003 |
| `GET /notice-config` | 小程序订阅模板 ID。未配置时返回空值 |

`entry.type` 显式给出 `WEB | MP_ARTICLE | MINIPROGRAM | CITATION_ONLY`，客户端不得自行把 `url` 当作可打开网页。Web 主题与小程序使用同一套查询逻辑。

## 微信小程序
- Phase 2，Web 先上线，不互相阻塞。
- 开发前关卡：个人主体实际注册、选类目、提交最小页面审核；确认 `web-view` 与公众号文章打开能力。
- 默认入口为 `CITATION_ONLY`（题名、来源、DOI、复制链接）。
- 若个人主体不可行：方案 A 只做 Web + 公众号；方案 B 注册个体户/企业主体。**待用户决定。**

2026-11-20 增补一次性新资料订阅。小程序提交 `POST /notice-subscriptions` 后由服务端校验微信登录码。匿名接口仅允许登记或取消该微信用户的授权，订阅记录不可公开读取。部署配置和验收见[微信云托管说明](../../deploy/cloudrun/README.md#小程序新资料订阅)。

## 微信公众号
- 个人订阅号，手动运营，发布原创导读，"阅读原文"指向 Web。
- 首版不开启服务器配置（开发者模式），不做自动回复与 AI 问答。
- Web 域名必须完成 ICP 备案。
