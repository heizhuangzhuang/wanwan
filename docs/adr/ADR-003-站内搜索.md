# ADR-003：站内搜索

状态：已采纳｜日期：2026-11-17

## 决策
插件维护一个内存倒排索引，仅包含**已发布**资料卡的：标题、显示标题、自写介绍、来源站名、作者/机构、主题标签。中文按字 bigram 切分，英文按词小写切分。

- 构建时机：插件启动全量构建；资料卡变更时增量更新（监听 Extension 变化）。
- 查询：关键词 ≤ 100 字符，每页 ≤ 50 条；按命中词数 + 人工推荐顺序排序。
- 返回前按主数据再次核验发布状态，防止索引滞后泄露已撤回内容。
- 无结果返回空列表，不调用模型、不联网。
- 不记录完整访客搜索词。

2026-11-21 增加公开原创导读搜索。关键词按不区分大小写的子串匹配 Halo 公开文章的标题和摘要，沿用发布日期降序和名称排序。Halo 文章没有阶段字段，选中具体阶段时返回该阶段的资料卡。导读与资料卡在同一页分别展示，任一组还有命中就可翻页。原有 `total` 和 `items` 保持资料卡含义，新增 `guideTotal` 和 `guideItems`。

## 理由
预期资料量为百级到千级，内存索引成本可忽略；Halo 自带搜索的中文效果和自定义字段覆盖不可控，且不能保证双端一致。

## 重新评估条件
资料量超过 1 万条，或需要语义搜索时。
