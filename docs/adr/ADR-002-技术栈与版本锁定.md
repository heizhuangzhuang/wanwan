# ADR-002：技术栈与版本锁定

状态：已采纳｜日期：2026-11-17

| 层 | 选型 | 锁定版本 |
| --- | --- | --- |
| 内容后端 | Halo 社区版（Spring Boot 3 / WebFlux / R2DBC，GPLv3） | `halohub/halo:2.27.3` |
| 插件 | Java + Gradle + `run.halo.plugin.devtools` | Java 21，平台 BOM `run.halo.tools.platform:plugin:2.27.3` |
| 插件 Console UI | Vue 3 + TypeScript + `@halo-dev/components` | 随 starter，pnpm 9 |
| Web 主题 | 自研 `theme-wanwan`，Thymeleaf | 待 P2 创建 |
| 数据库 | MySQL | `mysql:8.0` |
| 小程序 | 微信原生 + TypeScript | Phase 2 |
| 部署 | Docker Compose：Nginx + Halo + MySQL，单台大陆服务器（2C4G 级） | 见 `deploy/` |
| 备份 | 每日 `mysqldump` + Halo 工作目录打包，异地保留 30 天 | 见 `deploy/backup.sh` |

## 规则
- 不使用 Halo SNAPSHOT / beta 版本进入生产。
- 升级 Halo：先在备份副本上恢复并回归插件与主题，再切换生产。
- 不引入 Redis、MQ、Elasticsearch、向量库、微服务；如需引入，新建 ADR。
- 机密值只放 `.env`（不入 Git），仓库仅提供 `.env.example`。
