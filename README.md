# 弯弯 Wanwan

面向产前发现胎儿疑似足内翻的孕妇及家庭，由个人整理运营的阶段式知识导航。

当前方案：手动精选资料，展示必要标题、来源、自写简短介绍与合法原文入口。覆盖产前发现、出生后评估与治疗资料、支具生活及长期随访等主题。

## 当前范围

- Halo 社区版作为 Spring Boot 内容后台，Web 使用主题，原生小程序读取同一套公开资料。
- 首版由运营者逐篇手动精选录入；不自动采集全文，不默认复制配图或论文摘要。
- 搜索只覆盖已发布的题录、本站介绍和允许公开的原创内容。
- 公众 RAG 后续独立评估，腾讯 ADP 为候选；后台 AI 不是首版依赖。
- 不开放论坛、评论、私信、报告上传或个体医学判断。
