# 弯弯 Wanwan

胎儿足内翻全流程支持平台的项目规划与产品资料，面向孕妇及家庭，覆盖超声发现、产前评估、检查与报告解释、专业咨询、出生后治疗及长期随访。

## 项目文档

- [商业计划书目录](docs/business-plan/README.md)
- [完整商业计划书与详细流程图](docs/business-plan/business-plan.md)

计划书包含全流程用户故事、43个场景、医生分工及待开展的审阅任务、系统解决方案、商业模式和验证路径。第4节提供总流程图、3张分支图及14步行动清单。

## 当前阶段

项目处于规划与需求验证阶段。产品功能、医生合作和商业模式为拟议方案；文档中的医生审阅任务尚待执行，不代表已有真人专家评审或机构合作。

医学相关内容用于产品规划和就诊沟通准备，具体检查与治疗由接诊团队结合个体情况确定。现有版本不含预算。
