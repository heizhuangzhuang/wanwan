# 小脚丫步步指南微信小程序

微信原生小程序使用 TypeScript，复用 Halo 公开 API。读者可按阶段、类型和标签查找资料，按阶段和类型筛选搜索结果，浏览有序专题及本站原创导读。详情重新进入前台时检查内容是否仍可访问。

五个阶段页内置家庭准备事项、分阶段沟通问题和工具入口，后台资料加载失败时也可使用。「工具」中的就诊与经验目录提供医院、好大夫、小红书和抖音的可复制搜索词，附机构或医生的公开出处。渠道收录由运营者核对，账号状态与号源以原平台为准。

首页、底栏和常用工具使用本地 PNG 图标，取自 [Lucide 0.468.0](https://github.com/lucide-icons/lucide/releases/tag/0.468.0)。授权说明随图标存于 `assets/icons/`。

## 微信开发者工具与后端接入

在微信开发者工具中导入本目录。[project.config.json](./project.config.json) 中的 `touristappid` 用于本地开发。云端联调时，在开发者工具中换成已绑定 `prod-d1gm7gr9e711335be` 的真实小程序 AppID。 [app.ts](./app.ts) 已配置环境 ID 和服务名 `xiaojiaoya`，对外联系邮箱由运营者填写。

使用真实 AppID 时，小程序通过 `wx.cloud.callContainer` 请求微信云托管，服务名通过 `X-WX-SERVICE` 传递。游客 AppID 使用 `apiBase` 做本地 HTTP 联调，默认端口为 `18090`。如使用本地 Compose，将端口改为 `8090`。清空 `apiBase` 可在游客模式下浏览演示资料。 [部署架构](../docs/adr/ADR-005-前后端分离与微信云托管部署.md)

## 本地演示

在微信开发者工具的编译模式里选择「刚发现（本地 MySQL）」，开发版会连接 `127.0.0.1:18091` 的 MySQL 联调 Halo，读取 [六条虚构资料卡](../content/fixtures/just-found.json)。本地 Web 指向同一个 Halo API 时可读取相同资料。另有「公众号专题入口（本地演示）」和「公众号导读入口（本地演示）」两种落地路径。带 `demo=1` 的入口在开发版使用内置数据。切回普通编译后继续使用实际后端。

「工具」分别提供石膏记录与复诊提醒、矫正鞋穿戴记录。穿戴记录用本机存储保存正在计时的一段和历史时段，断网时仍可使用。近 7 天快速切换，历史明细也可选日期。跨午夜按天拆分，重叠计时取并集。每日目标由家长按医嘱填写。 [需求与验收](../docs/产品需求与内容规范.md#7-矫正鞋穿戴记录)

## 公众号文章入口

运营者从微信公众平台编辑和发布文章，在账号实际支持的关联小程序入口中使用以下页面路径。`name` 是已发布内容的 Halo 资源名称，需做 URL 编码。将示例中的 `topic-a`、`guide-a`、`resource-a` 换成已发布的实际名称。

| 文章希望打开的内容 | 页面路径 |
| --- | --- |
| 专题详情 | `pages/reading/reading?kind=topic&name=topic-a` |
| 本站原创导读 | `pages/reading/reading?kind=guide&name=guide-a` |
| 单张资料卡 | `pages/detail/detail?name=resource-a` |
| 足内翻超声复查清单 | `pages/downloads/downloads` |
| 已批准的资料附件 | `pages/downloads/downloads?resource=resource-a` |
| 资料首页 | `pages/index/index` |

运营者用实际公众号和小程序验证账号关联、文章卡片或可用入口、目标页与原文跳转。专题或导读下线时，入口显示不可访问，并可返回资料首页。原创导读在小程序里以文字呈现，保留段落和列表。完整图文与外链可在网站的原创导读页阅读。

资料详情根据后端给出的 `entry.type` 和核对状态开放来源入口。公众号文章或其他小程序跳转失败时，页面保留题录及手动复制入口。待核对或已撤回的资料只复制题录。实际公众号关联、云托管和真机跳转仍待接入验收。

在仓库根目录运行：

pnpm --dir web install --frozen-lockfile

## 当前体验

底部有四个一级栏目。详情使用微信页面栈返回到来源栏目。已有公众号专题、导读和下载路径可继续使用。

- 首页选择当前阶段后保存本机偏好，切换入口统一更新阶段与常用工具；下方「全部阶段资料」用于随时浏览其他阶段。
- 资料保留搜索、阶段筛选与产前检查专项，下方以单列图文流连续阅读原创导读、文献译读和资料卡。支持摘要展开、文章封面预览、逐条分享与滚动加载，返回时保留批次并重新核对公开状态。
- 工具按首页的当前阶段优先排列就诊准备、石膏与复诊、支具与随访，各组始终可访问；长期随访阶段优先显示复诊摘要。
- 我的集中提供本机收藏与最近阅读、已下载文件、微信提醒和反馈。收藏回访时重新核对资料可见性。

资料搜索、专题与详情复用 Web 使用的 Halo 公开 API。成功搜索的最近八条关键词仅存在本机，可点选重用或确认后清空。专题及原创导读的分享卡片直达公开内容；加载失败或内容撤回时回到资料库。

## 原创文章按阶段发布

在 Halo 控制台的「内容 → 文章 → 分类」中建立与阶段同名的分类。已有同名且未从列表隐藏的分类可以直接使用。新建分类时可按下表设置别名。

| 分类名称 | 别名 |
| --- | --- |
| 刚发现 | `just-found` |
| 产前了解与等待 | `prenatal` |
| 出生后评估与治疗 | `postnatal-treatment` |
| 支具与日常生活 | `brace-daily` |
| 长期随访与预后 | `long-term` |

在文章的「设置 → 分类目录」选择一个或多个阶段，然后公开发布。升级对应后端与前端后，阶段页会展示归类的原创导读，同一文章也会出现在总导读列表。小程序会保留标题、段落、列表、强调、引用与表格排版，文内链接以可选中文字显示；公开 HTTPS 的 JPG、PNG、WebP、GIF、AVIF 图片可在正文中显示，不支持的图片保留替代文字。

文章摘要建议在 Halo 中人工填写，简短说明读者能了解什么。小程序的资料库、阶段页与导读目录共用预览规则：去除重复标题；自动摘取的英文原题、文献出处等引用头部，以及空摘要，改为中性的阅读提示。该规则仅处理卡片预览，正文和引用信息仍完整保留。阶段页直接展示三项重点，点「查看重点详解」阅读具体说明。

## 资料下载

「工具」和「就诊沟通清单」均可打开足内翻超声复查清单。内置 PDF 来自 `web/public/downloads/clubfoot-ultrasound-checklist.pdf`，与 Web 文件一致，可在离线时写入小程序的用户文件目录。更新 PDF 后，从仓库根目录运行 `node miniprogram/test/sync-checklist.cjs`，再运行公开流程测试验证内容一致。

已公开且链接正常的资料卡可配置获准公开下载的 HTTPS 附件。运营者在 Halo 资料卡填写地址、带后缀的文件名，并确认公开下载许可。微信公众平台须放行附件主机的 `downloadFile` 合法域名。附件先下载，再保存到小程序用户目录。

「我的 → 已下载」在本机目录中识别已保存文件，可查看清单和已登记附件，也可单独移除。原版 PDF 离线可打开，第三方附件从资料入口重新核对当前许可和版本。升级前保存的附件在重新打开原下载页后补录文件名，旧副本可在列表清理。

PDF、Word、Excel 和 PPT 使用微信文档预览。图片可保存到手机相册。支持的文件可转发到微信会话，再从手机提供的选项导出。ZIP 使用下载和转发流程。真机验证时覆盖 iOS、Android、清单离线、文件转发、相册权限、远程下载域名和附件撤回。

## 家庭工具与产前检查专项

从底部「工具」可打开石膏记录、就诊沟通清单与 PDF。从底部「资料」进入产前检查专项，可按目录分组浏览，或用羊穿、CMA、WES 等简称搜索。详情可复制就诊问题及资料出处。产前专项内容不依赖 Halo；编辑 `web/public/guides/prenatal.json` 后，在根目录运行 `node miniprogram/test/sync-prenatal-guides.cjs`。专题入口可从公众号链接到 `pages/prenatal/prenatal?key=amniocentesis` 或 `pages/prenatal/prenatal?key=exome`。

石膏记录位于 `pages/cast/cast`。开启后使用当前微信账户识别本人。首次保存前由本人或监护人单独确认，照护事项与时间由家长手动填入。提醒需再次向微信申请一次性授权。变更复诊时间后，原有待发提醒取消。个人记录页禁止小程序搜索索引。

公开读取先走新 API。在云托管仍返回 Halo 登录页时，客户端兼容旧公开路径。石膏记录只使用新 API，配置缺失时显示暂未开放。云配置、真机步骤见[微信云托管部署说明](../deploy/cloudrun/README.md#石膏记录与复诊提醒)。

## 资料图文阅读流

布局与验收说明见[设计文档](../docs/小程序资料图文流设计.md)。图片二对应的搜索、阶段筛选、产前专项区域保持原有结构与样式。下方的横向导读卡片和独立资料区合并为纵向阅读流，文章和题录分别标明类型与真实来源。「阅读目录」位于内容区标题右侧，默认收起，展开后可进入原创导读、资料卡与专题；选择目录项目或切换阶段时自动收起。原先的底部大目录移除。

在 Halo 的文章设置中填写摘要、封面图并公开发布。封面使用有权公开展示、手机可访问的绝对 HTTPS 图片地址，支持 JPG、PNG、WebP、GIF、AVIF 及查询参数。新后端的文章列表与详情增加可选 `coverUrl` 字段，Web 与小程序共用同一接口；老后端缺少该字段时仍能使用文字阅读流。相对地址不会猜测补全为服务器地址，图片失败也不展示破损占位。

首屏请求 5 篇文章、3 张资料卡，之后按各自页码追加。滚动加载失败时保留已有内容，并仅重试失败的批次；切换阶段会清空旧阶段并丢弃迟到响应。返回资料页会重新核对已加载批次，清除已撤回的内容，保留剩余内容的相对顺序。由流中的「阅读全文」进入文章时默认展开全文，原有分节入口继续支持章节浏览。
